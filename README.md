# 🚀 AHNHYUNGJIN GitHub & Vercel 통합 프로젝트 허브

GitHub 저장소에 공개 및 보관된 모든 프로젝트, 개발 가이드, 체육/스포츠 웹 앱, AI 도구들을 한눈에 검색하고 접속할 수 있는 마스터 포트폴리오 웹 대시보드입니다.

## 🌟 주요 기능
- **실시간 검색 & 카테고리 필터링**: 라이브 배포 앱, 체육/스포츠, AI/개발 가이드, 툴/유틸리티별 필터
- **원클릭 접속 링크**: Vercel 실시간 서비스 URL 및 GitHub 소스코드 저장소 바로가기
- **통계 대시보드**: 총 프로젝트 및 라이브 배포 서비스 실시간 집계

## 🛠️ 기술 스택
- HTML5, Vanilla CSS (Glassmorphism & Slate Dark Theme), Vanilla JS
- GitHub CLI / Vercel CLI 자동 배포
